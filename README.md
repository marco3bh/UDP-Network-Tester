# MBH UDP Network Tester

A Python-based UDP network testing tool featuring a Windows command-line interface, custom ASCII banner, and configurable test parameters.

## Features

- Custom Windows CLI interface
- ASCII banner
- UDP packet transmission
- Three packet-size modes
- Configurable target loopback IP and port
- Adjustable test duration and packets per second
- Basic network statistics
- Localhost-only testing

## Requirements

- Python 3.10+
- Windows (for the batch launcher)

## Usage

1. Clone or download this repository.
2. Run `MBH-DDOS.bat`.
3. Select a testing mode.
4. Enter the local target IP, port, duration, and packet rate.
5. Review the test statistics.

## Disclaimer

This project is intended exclusively for educational purposes and authorized local network testing.

It is not designed for disrupting third-party services or networks.
